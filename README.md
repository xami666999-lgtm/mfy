## What MFY is

A desktop / phone frontend for titles you already have rights to watch. Metadata from TMDB and similar. Playback uses stream URLs you configure.

---

## Features

Home hero + title logos, Continue Watching, Movies / TV / Anime, Calendar, YouTube, Music, Sport, IPTV, Manga / Comics / Books, Library, SIMKL / Serializd ratings, built-in HLS/DASH player.

Phone wrap uses bottom tabs (Home / Movies / Shows / Anime / More).
