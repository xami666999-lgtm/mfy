# MFY Mockup Match

The Board is intentionally shaped around the supplied reference/mockup:

- Black/purple desktop surface with restrained neon-pink accents.
- Horizontal top navigation instead of a sidebar.
- Compact MFY logo + name at the left.
- Large bordered cinematic hero directly below the navbar.
- Hero copy on the left with Play, Add to List and Info controls.
- Provider strip immediately below the hero with 10 real provider PNGs.
- Large square provider marks with names underneath.
- Horizontal poster rows with View All on the right and a floating next arrow.
- Pink hover borders/glow instead of excessive cards, gradients or glassmorphism.
- Responsive fallback keeps the same visual hierarchy on smaller windows.

The supplied pink MFY film/play mark is now the desktop app icon, favicon, tray icon source and avatar asset.
